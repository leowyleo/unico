# Unico 隐私政策

公开地址：<https://unico.leowy.cc/privacy>
中文地址：<https://unico.leowy.cc/zh/privacy>

Unico 仅在用户主动选择的位置（直接下载版另有明确发起的内置磁盘扫描）本地读取文件信息与内容，用于识别完全重复的文件。文件、路径、元数据、扫描结果和设置不会上传；应用不使用账号、广告、跟踪、分析服务或第三方 SDK。

只有用户确认的副本会被移动到 macOS 废纸篓；Unico 不会自动删除、永久擦除或清空废纸篓。

支持邮箱：<leowy.lwy@gmail.com>。GitHub Issues 也是正式支持渠道。
