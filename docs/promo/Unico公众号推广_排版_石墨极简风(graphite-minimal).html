同一张图片，下载过，又从聊天里存过；整理资料时，换个文件夹再复制一份。过了一阵，连自己也分不清哪份该留。

想清理，又不敢随便删：它们真的一样吗？会不会删错？

做完截图工具 Clip，这次我做了 Unico：一个免费开源的 Mac 重复文件查找工具。先把重复的找出来，让你看清楚，再决定留哪份。

01

COMPARE

找重复，看内容

文件名不同，内容也可能一样。Unico 会比较文件内容，确认完全相同后，才把它们归为一组。

先选一个熟悉的文件夹，也可以把下载、桌面、归档几个目录一起加入，跨目录比较。支持扫描内置磁盘，只是耗时可能更久。

这一版只找完全重复的文件，暂不支持相似图片查找。“看着差不多”，不会被当成同一份。


02

KEEP

看清楚，留一份

找到重复之后，最重要的问题是：留哪份？点击文件，就能查看支持的预览，以及名字、位置和创建时间。

— 亮色主题下的真实界面：重复组、文件预览与保留项

Unico 默认推荐保留创建时间最早的一份，但不代表它一定是原件。你可以换一份保留，也可以取消某个副本的清理。

确认后，多余副本才会移到废纸篓。清理前还会再次核验文件，每组至少留下一份。

选范围 → 看预览 → 决定保留项 → 确认清理。

有一点别忽略：内容相同，不代表每个位置都能删。两个应用或项目，可能各自都需要这份文件。

全盘扫描默认跳过系统、应用内部和已识别的开发项目等位置。主动选择文件夹并确认风险后，可以覆盖默认排除规则，但不等于里面的文件都适合删除。拿不准的，先留着。

Unico 不永久删除，也不清空废纸篓。移入废纸篓不会立即释放空间，界面显示的大小也不等于实际可回收空间。


03

OPEN SOURCE

一个小工具，保持简单

和 Clip 一样，我希望它打开后就能知道怎么用，不用先研究一页设置。

完全在本机运行，无需账号，不上传文件，没有订阅，也不后台监控文件。默认英文，可在标题栏切换中文。

Unico 已以 MIT 协议开源，社区预览版可以免费下载。

DOWNLOAD

项目地址：https://github.com/leowyleo/unico
下载地址：https://github.com/leowyleo/unico/releases/tag/v1.1.3

下载 DMG，双击打开，把 Unico.app 拖进“应用程序”。先用熟悉的小文件夹试扫，重要文件请保留备份。

安装前也请留意：当前没有 Developer ID 签名，未经过 Apple 公证，首次打开可能被拦截。请阅读项目安装说明，只允许可信下载，不要全局关闭安全保护。

安装包包含 Apple 芯片与 Intel 两种架构，最低目标为 macOS 12。已在 Apple 芯片 Mac 实测，旧系统与 Intel 实机兼容性仍待验证。

试用后，欢迎告诉我：哪一步仍让你不敢点“清理”？ 这比再加一个功能，更值得先解决。

少一点重复，多一点从容。
