## 事实与边界

- 完全本地，无账号、无上传、无订阅。不依赖 AI 判断文件内容。
- 内容逐字节相同才算重复，不按文件名判断；相似图片查找尚未实现。
- 用户只需决定扫哪里、留哪份、是否清理。推荐保留不等于确认原件。
- 全盘扫描默认保护系统、应用、开发项目等；手动选择目录经风险确认可覆盖排除规则。
- 内容相同不代表每个路径都能删，删除应用或项目资源可能影响功能；清理前仍需确认。
- 只移到废纸篓，不清空废纸篓；不宣传“一键立即释放 X GB”。
- macOS 12 最低目标，Apple 芯片与 Intel 通用包。旧系统与 Intel 实机仍待验证。
- 当前社区版未经过 Developer ID 签名及 Apple 公证，首次安装可能被 macOS 提醒。
- 不使用“绝对安全”“零误删”“支持所有 Mac”“取代所有订阅工具”等未经证明的承诺。
