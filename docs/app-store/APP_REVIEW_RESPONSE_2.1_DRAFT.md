## Reply to App Review

Hello App Review,

Thank you for the additional-information request. Unico is ready for review. It is a native macOS utility for finding files with exactly identical contents and helping the user review which copy should remain. It addresses duplicate files that consume local storage and gives the user a reversible, reviewable cleanup flow.

### 1. Screen recording

Attached: `[待附：从启动 Unico 开始的实体 Mac 录屏]`.

The recording starts by launching Unico and shows the normal flow:

1. Launch Unico.
2. Choose a user-selected folder containing a small duplicate-file fixture.
3. Confirm the scan scope.
4. Scan and review the duplicate group, including previews, paths, sizes, and modification dates.
5. Keep the recommended newest copy or change the keeper manually.
6. Confirm moving the selected duplicate to macOS Trash.
7. Show that the file is moved to Trash rather than permanently erased.

The recording is captured on a physical Mac running the latest available macOS version at the time of resubmission.

### 2. Purpose and target audience

Unico is for Mac users who want to find exact duplicate files in folders they choose or on the internal disk. It compares file contents, not only filenames, then lets the user review each group and decide what stays. It is intended for general Mac users, creators, developers, and other people managing local storage.

### 3. Setup and access

No account, login, subscription, or special credentials are required.

To use the main feature:

1. Launch Unico.
2. Choose one or more folders, or choose the internal-disk scan.
3. Confirm the scope and start scanning.
4. Review duplicate groups and choose the keeper.
5. Confirm cleanup. Selected files are moved to macOS Trash and are not permanently deleted by Unico.

No external sample files are required. Any user-owned folder containing two or more files with identical contents can be used. The recording uses a temporary local fixture with duplicate files.

### 4. External services and platforms

Unico does not use external services to provide its core functionality. It has no account system, authentication provider, payment processor, cloud storage, AI service, analytics, advertising, tracking, or third-party SDK. File enumeration, comparison, previews, settings, and cleanup happen locally on the Mac.

The support website and GitHub Issues are only support channels; they are not used by the app to scan or process files.

### 5. Regional differences

Unico's functionality is consistent across regions. There are no region-specific features, paid content, or regional data providers. The app includes English and Simplified Chinese UI; if the Mac's primary language is another language, the UI falls back to English. This does not change scanning or cleanup behavior.

### 6. Regulated industries and protected material

Unico does not operate in a regulated industry and does not provide medical, financial, legal, communications, or other regulated services. It does not include protected third-party material. It is a local file-management utility.

Build under review: Unico 1.1.3 (7), bundle identifier `cc.leowy.unico`.

Please let us know if any additional information is needed.
