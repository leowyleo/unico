Getting started

Choose one or more folders, then start a scan. Unico only groups files whose contents are exactly the same. Review the proposed copies before moving anything to the Trash.

No results or missing files

  • Choose folders rather than individual files.
  • Check the scan types and minimum-size rule in Settings.
  • Files in protected locations, application bundles, links, hidden locations, dependencies, and caches are skipped for safety.

Before cleanup

Identical contents do not mean every copy is safe to remove. Keep files needed by an app or project, and make sure you have a backup. Files moved by Unico can be restored from the Trash before it is emptied.
