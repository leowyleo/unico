Unico Privacy Policy

Last updated: September 10, 2026

Operator: Leowy · 运营者：行与未见

Local processing

Unico finds exact duplicates by reading file names, paths, sizes, modification dates, and file contents only on your Mac. It scans folders you choose. In the direct-download edition, an internal-disk scan can be started only when you explicitly choose it.

Local settings

Unico stores scan preferences, including chosen file categories, ignored locations, and duplicate-handling preference, locally on this Mac.

What Unico does not do

  • It does not upload files, metadata, scan results, or preferences.
  • It does not use accounts, advertising, tracking, analytics, or third-party SDKs.
  • It does not automatically delete files.

File operations

Only the copies you confirm are moved to the macOS Trash. Unico does not permanently erase files or empty the Trash.

Contact and changes

For help or to report a problem, use the support page, email leowy.lwy@gmail.com, or file an issue on GitHub. If these practices change, this page will be updated with a new date.
