运营者：行与未见 · Operator: Leowy

开始使用

选择一个或多个文件夹后开始扫描。Unico 只会将内容完全相同的文件归为一组；移动到废纸篓前，请逐组确认待清理副本。

没有结果或文件缺失

  • 请选择文件夹，而不是单个文件。
  • 检查设置中的文件类型和最小文件大小规则。
  • 为保证安全，受保护位置、应用包、链接、隐藏位置、依赖和缓存会被跳过。

清理前

内容相同并不表示每一份副本都可以删除。请保留应用或项目依赖的文件，并先确保已有备份。Unico 移动的文件在清空废纸篓前都可恢复。
