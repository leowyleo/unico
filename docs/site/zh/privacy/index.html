本地处理

Unico 只在你的 Mac 上读取文件名、路径、大小、修改日期和文件内容，以找出完全重复的文件。它扫描你主动选择的文件夹；在直接下载版中，只有你明确发起时才会扫描本机内置磁盘。

本地设置

Unico 会在这台 Mac 本地保存扫描偏好，包括选择的文件类型、忽略位置和重复项处理偏好。

Unico 不会做什么

  • 不会上传文件、元数据、扫描结果或设置。
  • 不会使用账号、广告、跟踪、分析服务或第三方 SDK。
  • 不会自动删除文件。

文件操作

只有你确认的副本才会被移到 macOS 废纸篓。Unico 不会永久删除文件，也不会清空废纸篓。
