# Unico：第一版开发计划

产品名称：**Unico**。定位：重复文件查找与清理工具。

## 目标

做一个独立于 Clip 的 macOS 小工具：找出多余副本，让用户看清楚，再安全清理。

用户只需决定三件事：扫哪里、留哪份、是否清理。追求简约、高级、克制、美观，不增加无必要的选项。

## 第一版范围

- 免费查找常见个人文档、图片、音视频和压缩包中的“完全重复”：内容完全一致才算重复；名称相同不是依据。
- 支持选择或拖入一个或多个文件夹，包含子文件夹，并跨所选目录比较。
- 支持全盘扫描：仅本机内置磁盘；开始前提示可能耗时较长。
- 全盘扫描默认排除隐藏目录、系统文件、程序与配置、开发项目、图库及未知类型。用户主动选择的文件夹优先于这些排除规则：开始前提示风险并确认，随后按所选目录及子目录扫描全部普通文件；授权只对本次范围生效，不设全局开关。
- 不自动扫描移动硬盘、NAS 或网盘；用户可通过指定文件夹主动添加可访问的位置。
- 相似查找仅考虑图片，留到后续作为付费高级功能。第一版不实现，不放锁定入口或升级广告。

## 界面与操作

只保留一个主窗口，呈现三个状态：

1. **选择范围**：拖入或选择文件夹，或选择“扫描本机”，开始扫描。
2. **扫描中**：显示当前进度、已发现的重复项，支持取消；无法读取的位置明确提示，不当作已扫描。无法准确计算进度时，不显示虚假的百分比。
3. **查看与清理**：左侧显示重复组，按预计可清理大小从大到小排列；右侧显示当前组预览、文件名、路径、大小和“保留／待清理”标记。

每组默认保留创建时间最早的一份，其余预选待清理。标明“推荐保留”，不称“原件”；用户可更换保留项，也可取消清理某个副本。

预览可选，不要求逐组查看。支持系统可预览的文件；无法预览时仍显示文件信息。

底部固定显示已选数量、文件总大小及“移到废纸篓”按钮。执行前统一确认一次，结束后在当前窗口显示成功与失败数量。

## 不可突破的安全约束

- 内容相同不代表所有路径都可删。手动目录经确认可覆盖默认排除规则，清理时沿用同一范围；文件身份与内容复核、链接保护、至少保留一份始终生效。删除应用、系统或项目文件可能导致功能失效，清理前明确提示并确认。
- 每组至少保留一份，不允许整组删除。
- 只移到废纸篓，不提供永久删除；无法移入废纸篓时跳过并提示，不改为直接删除。
- 提示清空废纸篓后才释放空间；文件总大小不承诺等于实际释放空间。
- 清理前重新检查保留文件和待清理副本；文件被修改、移动或无法确认一致时跳过。
- 同一文件被重复扫描、符号链接和硬链接不能作为普通多余副本误清理。
- 无权限时明确说明，不自动提权或绕过权限。

## 实现方向

采用 Swift 与 macOS 原生界面能力；本地扫描和处理，不需要账号、云服务或 AI。

扫描按文件大小筛选候选，再校验内容；不能仅凭名称、大小或时间判定重复。使用后台任务，扫描和清理期间界面保持可操作。

视觉跟随系统深浅色，以灰阶、一个强调色、清晰字体层级和留白为主。预览是主体，不做仪表盘、评分、复杂策略设置或装饰性动画。

## 开发顺序与完成标准

1. **先查得准**：完成指定文件夹与本机扫描、排除规则、取消和重复分组。用已知样本确认不同名同内容能找到，同名不同内容不会误判。
2. **再看得清**：完成结果列表、预览、自动推荐、更换保留项和取消选择。使用真实文件走通操作。
3. **最后安全清理**：完成确认、清理前复查、移到废纸篓及失败反馈，打包为可运行的 Mac 应用。

验收以真实应用操作为准：选择范围 → 扫描 → 预览 → 调整保留项 → 确认清理；保留文件完整，多余副本可从废纸篓恢复。另验证取消扫描、权限不足和扫描后文件变化不会造成误删。

完成以上闭环即结束第一版，不继续追加高级功能。
